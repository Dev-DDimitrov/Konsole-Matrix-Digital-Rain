# Welcome

I want to share this project out of love for Linux, KDE/Konsole, the Matrix
aesthetic, and the technology and culture around it. It is a small utility for
turning a familiar terminal visual into something polished, controllable, and
pleasant to use every day.

Konsole Matrix Digital Rain brings together the renderer, Konsole profiles,
multi-monitor presentation, saved visual settings, and an optional idle-aware
controller without requiring a collection of unrelated terminal tricks. The
goal is to give Fedora and KDE users a useful starting point while keeping the
implementation local and understandable.

Start with:

    matrix-guide
    matrix-doctor
